# portfolio_iseki

自己紹介として制作したポートフォリオのサイトです。

## 概要

Webデザインやコーディングの学習を通して制作した、
自身のプロフィールや制作実績などを紹介するポートフォリオサイトです。

「シンプルで見やすく、親しみやすいデザイン」を意識して制作しました。

## 使用技術

- HTML
- CSS
- JavaScript
- Vite
- particles.js
- Splide

## 制作内容

- ポートフォリオサイトのデザイン・コーディング
- レスポンシブ対応（PC・スマートフォン）
- ハンバーガーメニュー
- Intersection Observerを使用したスクロールアニメーション
- Splideを使用したスライダー
- お問い合わせフォーム
- GitHub Pagesで公開

## デザインについて

水玉や淡いグラデーションを使用し、
明るく親しみやすい雰囲気になるようにデザインしました。

各セクションでは縦書きのタイトルやグラデーションを使用し、
サイト全体で統一感が出るようにしています。

## ページ構成

- Home
- Works
- Profile
- Other
- Contact

## 工夫した点

### レスポンシブ対応

PCとスマートフォンの画面幅に合わせて、
レイアウトや背景画像を切り替えています。

### スクロールアニメーション

Intersection Observerを使用し、
各セクションのタイトルがスクロールに合わせて表示されるようにしました。

### スライダー

Splideを使用して、趣味の写真をcanvaのフレームを使い画像加工して紹介するスライダーを実装しました。
